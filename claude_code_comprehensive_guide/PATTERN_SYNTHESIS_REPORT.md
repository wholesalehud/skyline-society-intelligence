## Multi-Agent Orchestration Patterns

### Coordination Patterns Documented

**1. Pipeline Orchestration**
- Linear workflow with sequential stages
- Example: Portfolio analysis (data → analysis → decision)

**2. Fan-Out/Fan-In**
- Parallel processing with aggregation
- Example: Batch stock analysis

**3. Adaptive Routing**
- Dynamic agent selection based on task characteristics
- Example: Complexity-based model selection

**4. Iterative Refinement**
- Multi-loop improvement with convergence
- Example: BSHR research validation

### Real-World Workflow Example

```python
# Portfolio Validation Workflow (from patterns)

# 1. Parallel data collection (haiku)
market_data = await delegate_to_agent('market-data-agent', ticker)
earnings_data = await delegate_to_agent('earnings-analyst-agent', ticker)
sentiment_data = await delegate_to_agent('sentiment-agent', ticker)

# 2. Analysis (sonnet)
risk_report = await delegate_to_agent('risk-assessment-agent', {
    'ticker': ticker,
    'market_data': market_data,
    'fundamentals': earnings_data
})

# 3. Decision (opus)
trade_ticket = await delegate_to_agent('trade-ticket-agent', {
    'earnings': earnings_data,
    'risk': risk_report,
    'sentiment': sentiment_data
})

# 4. Knowledge preservation (haiku)
await delegate_to_agent('vectorization-agent', trade_ticket)
```

**Estimated Cost:** $0.024
**vs All-Opus:** $0.150 (84% savings)
